Fonts bundled with the app (both under the SIL Open Font License 1.1, see the
OFL files next to them).

GoogleSansCode.ttf   Google Sans Code, variable (wght 300-800), unmodified, from
                     github.com/google/fonts, ofl/googlesanscode. Used for every
                     number and code identifier.
GoogleSansFlex.ttf   Google Sans Flex from github.com/google/fonts,
                     ofl/googlesansflex. The original has five axes (3.9 MB). To
                     keep the app small, this copy pins ROND=0, slnt=0, wdth=100
                     and opsz=20 and keeps the weight axis (300-800), made with
                     fontTools.varLib.instancer. All glyphs are kept.
