# Deploys and Releases

One line per event, newest first. `scripts/release-apk.sh` prints the row to add after each release.

The QR code in the README ([docs/apk-qr.png](docs/apk-qr.png)) and on the "Try it yourself" slide points at
https://github.com/keepdeploying/faster_flutter_ffi_ai/releases/latest/download/faster-flutter-ffi-ai.apk,
which always serves the newest release, so it never needs to change.
